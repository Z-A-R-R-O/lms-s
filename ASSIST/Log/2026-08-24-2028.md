# Generated program artwork

## Scope

- Generated six original program cover images with the built-in image-generation workflow.
- Added optimized WebP assets for Full Stack Development, Data Science & AI, UI/UX Design, Cloud Computing, Product Management, and Generative AI.
- Added accessible image metadata to the shared public program model.
- Filled the homepage program cards, catalog cards, detail-page hero, enrollment media, and related-program cards with the new artwork.
- Preserved HTML headings and labels instead of embedding text inside the generated images.

## Asset treatment

- Source artwork was resized to a maximum width of 1600 pixels.
- Final WebP assets are 78–213 KB each.
- Decorative hero artwork uses an empty alternative description; meaningful card and enrollment artwork uses program-specific descriptions.
